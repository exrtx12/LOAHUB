사이트나 기능 추가 요청

목록에 없는 좋은 도구를 알고 계시다면 알려주세요. 로스트아크 관련 유저 사이트라면 어떤 것이든 검토합니다. 사이트 이름과 주소, 어떤 기능이 좋은지 한 줄만 적어주시면 충분합니다.

이미 있는 사이트라도 아직 등록되지 않은 기능이 있을 수 있습니다. 그런 제보도 환영합니다.

링크 오류 신고

가장 도움이 되는 문의입니다. 각 사이트가 개편되면 링크가 깨지는데, 운영자가 매번 전부 확인하기는 어렵습니다.

클릭했을 때 페이지를 찾을 수 없거나, 엉뚱한 곳으로 가거나, 사이트 메인으로만 넘어간다면 알려주세요. 어느 도구인지만 적어주시면 됩니다.

사이트 운영자분의 요청

LOAHUB에 링크된 사이트를 운영하고 계시고 게재를 원하지 않으신다면 말씀해 주세요. 확인하는 대로 즉시 삭제합니다. 사유를 설명하실 필요도 없습니다.

파비콘 표시, 기능 설명 문구, 연결 방식에 대한 요청도 마찬가지로 반영합니다. 소개 문구가 사실과 다르다면 정정하겠습니다.

오탈자와 잘못된 설명

기능 설명이나 가이드 글에 틀린 내용이 있으면 알려주세요. 게임 업데이트로 도구의 용도가 바뀌는 경우도 있어서, 이런 제보가 특히 유용합니다.

기능 제안

지금은 캐릭터 검색, 분류 필터, 즐겨찾기 정도가 전부입니다. “이런 게 있으면 좋겠다” 싶은 것이 있으면 알려주세요. 실제로 지금 있는 기능 상당수가 이용자 의견에서 나왔습니다.

그 밖에

개인정보 관련 문의, 광고 관련 문의, 기타 제안 모두 같은 주소로 보내주시면 됩니다.

보내실 때 참고

이런 내용이 있으면 처리가 빠릅니다

링크 오류 — 어느 도구인지, 눌렀을 때 어떻게 됐는지
사이트 추가 — 사이트 이름과 주소, 추천하는 기능
게재 중단 — 운영하시는 사이트 주소

스크린샷을 첨부해주시면 더 좋지만 필수는 아닙니다. 짧게 한 줄만 보내주셔도 확인합니다.

답변에 대해

LOAHUB는 개인이 취미로 운영하는 사이트입니다. 상시 대기하는 상담 창구가 아니라서 답변까지 며칠 걸릴 수 있습니다. 양해 부탁드립니다.

다만 사이트 운영자분의 게재 중단 요청은 최우선으로 처리합니다. 다른 문의보다 먼저 확인하고 즉시 반영하겠습니다.

링크 오류처럼 바로 고칠 수 있는 것은 확인 즉시 수정하고, 별도 답장 없이 반영만 되는 경우도 있습니다. 답장이 없더라도 사이트에서 고쳐졌는지 확인해보시면 됩니다.

LOAHUB에 대한 더 자세한 내용은 소개 페이지를, 개인정보 처리에 관한 사항은 개인정보처리방침을 참고해주세요.

LOAHUB는 개인이 만든 링크 모음집입니다. 각 기능은 원 사이트로 연결되며, LOAHUB는 해당 사이트들과 아무 관계가 없습니다.
